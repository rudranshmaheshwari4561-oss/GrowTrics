
# GrowTrics – E-Commerce Sales Intelligence App

### Growth with Analytics

## About the Project
GrowTrics is an E-Commerce Sales Intelligence application developed using Python. It helps businesses analyze their sales data and make better business decisions through interactive dashboards and machine learning.

## Features
- Sales and Revenue Analysis
- Monthly Revenue Trends
- Sales Forecasting using Linear Regression
- Top 10 Product Analysis
- Category and Regional Sales Analysis
- Customer Segmentation using RFM and K-Means
- Automated Business Growth Recommendations
- Data Cleaning and Downloadable CSV

## Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Scikit-learn

## Installation

Clone the repository:

```bash
git clone https://github.com/rudranshmaheshwari4561-oss/GrowTrics.git
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

## How to Use
1. Run the application.
2. Upload a CSV or Excel sales dataset.
3. Map the required columns.
4. Explore sales dashboards.
5. View forecasts and customer segments.
6. Get automated growth recommendations.

## Project Purpose
The main objective of GrowTrics is to convert raw e-commerce sales data into meaningful insights that help businesses improve their performance.
